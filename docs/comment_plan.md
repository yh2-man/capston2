# 댓글 기능 구현 계획

## 1. DB 설계

```sql
CREATE TABLE IF NOT EXISTS comments (
    id          BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    post_id     BIGINT NOT NULL REFERENCES community_posts(id) ON DELETE CASCADE,
    user_id     BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    content     VARCHAR(500) NOT NULL,
    created_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_comments_post ON comments(post_id, created_at);

-- community_posts에 comment_count 컬럼 추가
ALTER TABLE community_posts ADD COLUMN IF NOT EXISTS comment_count INT NOT NULL DEFAULT 0;
```

## 2. 백엔드 API

| HTTP | 엔드포인트 | 설명 | 인증 |
|------|-----------|------|------|
| GET  | `/api/v1/community/posts/{postId}/comments` | 댓글 목록 (최신순) | 불필요 |
| POST | `/api/v1/community/posts/{postId}/comments` | 댓글 작성 | 필요 |
| DELETE | `/api/v1/community/posts/{postId}/comments/{commentId}` | 댓글 삭제 (본인만) | 필요 |

### 응답 형식

## 3. Flutter 구현

### 3-1. 댓글 바텀 시트 (CommentBottomSheet)
- 피드에서 💬 댓글 버튼 탭 → 아래에서 위로 슬라이드 올라옴
- 오른쪽 상단 X 버튼 또는 아래로 드래그 → 슬라이드 내려가며 닫힘
- 구조:
  ```
  ┌─────────────────────┐
  │ ▬ (드래그 핸들)       │
  │ 댓글 N개    [X]      │
  ├─────────────────────┤
  │ 댓글 목록            │
  │ (스크롤 가능)         │
  │                     │
  ├─────────────────────┤
  │ [프로필] [입력창] [↑] │  ← 키보드 올라오면 같이 올라감
  └─────────────────────┘
  ```
- Flutter: `showModalBottomSheet(isScrollControlled: true)` + `DraggableScrollableSheet`
  - 드래그 핸들로 높이 조절 가능
  - 키보드 올라오면 입력창도 같이 올라감 (`padding: EdgeInsets.only(bottom: MediaQuery.of(context).viewInsets.bottom)`)

### 3-2. 댓글 아이템
- 프로필 이미지 + 닉네임 + 내용 + 시간
- 본인 댓글: 길게 누르면 삭제 확인 다이얼로그

## 4. 구현 순서

1. **Supabase SQL** 실행 (comments 테이블 + comment_count 컬럼)
2. **백엔드** - Comment 엔티티, Repository, Service, Controller
3. **Flutter** - PostDetailScreen 생성
4. **Flutter** - 커뮤니티 피드에서 상세 화면 연결
5. **Flutter** - 댓글 작성/삭제 API 연동

---

## 5. 주의사항

- 댓글 작성/삭제 시 `comment_count` 실시간 업데이트
- 댓글 삭제는 본인 댓글만 가능 (userId 검증)
- 댓글 목록은 페이지네이션 없이 전체 로드 (초기 구현)
- 게시글 삭제 시 댓글도 자동 삭제 (ON DELETE CASCADE)
